# Lattice_Eater v2  
**Human-Gated Autonomy Runtime**

> **"Autonomy that explains every decision — and asks permission."**

Built in **one day**. Runs **offline**. Logs **everything**.

---

## What It Is
A **local-first**, **auditable**, **self-tuning** autonomy engine.

- **20Hz simulation loop** → synthetic detections/alerts  
- **Auto-adjusts thresholds** using clarity + alert stats  
- **Every change logged** in tamper-proof SQLite  
- **Human veto/approval** via API  
- **Live metrics** → Prometheus `/metrics`  
- **Terminal cockpit** → Textual TUI  

**No cloud. No black boxes. No trust required.**

---

## Core Principles
| Principle | Implementation |
|---------|----------------|
| **Human in the Loop** | All tuning suggestions require approval |
| **Auditability** | Every tick, flush, and decision → SHA-256 ledger |
| **Observability** | `/metrics` + TUI = real-time insight |
| **Edge-Ready** | Runs on Raspberry Pi in a bunker |
